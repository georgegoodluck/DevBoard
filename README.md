# DevBoard

Production-grade SaaS project management tool. Team-based workspaces, real-time collaboration, Kanban boards, sprints, GitHub integration.

## Stack
Frontend: Next.js 15, TypeScript, Tailwind v4, ShadcnUI, TanStack Query v5, @dnd-kit
Backend: Fastify, Drizzle ORM, PostgreSQL (Supabase)
Deploy: Vercel (frontend), Render (backend)
